The Griffin command surface. For live help, run `griffin --help` and `griffin <command> --help`.

The bare `griffin` (no arguments) starts the local server and opens the **browser workspace** in your working directory. Everything else is grouped below.

## Global flags

| Flag | Use |
| --- | --- |
| `-v, --version` | Print the installed version. |
| `-h, --help` | Print help for a command. |
| `--print-logs` | Stream agent diagnostics to stderr. |
| `--log-level <DEBUG\|INFO\|WARN\|ERROR>` | Override the log threshold. |

## Workspace and runs

| Command | Use |
| --- | --- |
| `griffin` | Start the server and open the browser workspace. |
| `griffin run [message..]` | One-shot prompt in the terminal; streams, then exits. |
| `griffin session list` | List recent sessions (`-n`, `--format`). |

`run` flags: `-c/--continue`, `-s/--session <id>`, `-m/--model <provider/model>`, `--variant <high|max|minimal>` (provider-specific reasoning effort), `--agent <name>`, `--format <default|json>`, `-f/--file <path>`, `--attach <url>` (attach to a running server, e.g. `http://localhost:4096`), `--port`, `--title <text>`.

```bash
griffin run "Plot the attention entropy across layers for this checkpoint"
griffin run -c "Now sweep the temperature and re-plot"
griffin run --format json "Summarize the experiment in results/" > summary.json
```

## Account

Connecting an Atlas account is optional — see [Atlas](/griffin/atlas). Griffin runs fully standalone with your own provider keys.

| Command | Use |
| --- | --- |
| `griffin init` | First-run setup wizard — choose managed models, your own keys, or skip. Rerun anytime (alias `onboard`). |
| `griffin login` | Connect your Atlas account (browser flow, or `--key thk_…`). |
| `griffin status` | One view of your Atlas state — account, synced services, subscription, wallet balance + lifetime spend, recent usage, managed-compute availability, and the bundled `atlas` companion version (alias `whoami`). |
| `griffin sync` | Re-pull synced credentials. |
| `griffin devices` | List authorized devices. |
| `griffin logout` | Disconnect this device from Atlas. |
| `griffin doctor` | Report what's configured: account, provider keys, wallet, default model. |

`griffin connect …` still works as an alias for `login` / `logout` / `status` / `sync` / `devices`.

## Providers and routing

| Command | Use |
| --- | --- |
| `griffin keys add` | Add a provider API key (BYOK; OAuth sign-in where supported). Alias: `auth`. |
| `griffin keys signin` | Sign in with ChatGPT / Codex (subscription). |
| `griffin keys list` | List saved provider keys and active env vars. |
| `griffin keys rm` | Remove a saved provider key. |
| `griffin models` | List configured providers and their models. |
| `griffin wallet` | Wallet balance and key routing (alias `billing`). |
| `griffin wallet topup` | Open the app to add credit. |

## Sandbox

| Command | Use |
| --- | --- |
| `griffin sandbox` | Show sandbox status: OS backend + current policy. |
| `griffin sandbox enable` | Confine the agent's shell + notebook execution to the workspace (`--network deny`, `--allow <path>`, `--on-unavailable <warn\|error\|allow>`). |
| `griffin sandbox disable` | Turn the sandbox off. |
| `griffin sandbox test` | Prove containment on this machine (writes inside/outside the workspace, network egress). |

Off by default. See [Execution sandbox](/griffin/sandbox).

## Agent profiles

| Command | Use |
| --- | --- |
| `griffin agent list` | Print the agent roster on this install. |
| `griffin agent create` | Scaffold a custom agent (system prompt + tool set + routing policy). |

Flags: `--path`, `--description`, `--mode <all\|primary\|subagent>`, `--tools`, `--model`. See [Agents](/griffin/agents).

## Skills

| Command | Use |
| --- | --- |
| `griffin skill list` | Show installed skills (`--all` for the bundled set). |
| `griffin skill show <name>` | Print a skill's metadata and entrypoints. |
| `griffin skill add <url-or-name>` | Install a skill (URL or `gh:owner/repo`). |
| `griffin skill new` / `edit` / `validate` | Author, edit, and check user skills. |
| `griffin skill remove <name>` | Uninstall a skill. |
| `griffin skill set-entries <name>` | Update which skills surface in the `/` picker. |

## Local server and protocols

| Command | Use |
| --- | --- |
| `griffin web` | Start the server and open the browser workspace (prints the URL, e.g. `http://localhost:4096`). |
| `griffin serve` | Headless local server — loopback-only (`127.0.0.1`), no browser. |
| `griffin acp` | Start an Agent Client Protocol server for editors like Zed. |
| `griffin mcp` | Manage MCP servers (`list`, `add`, `remove`, `auth`). |

`web` and `serve` take `--port` and `--cors`. See [Workspace](/griffin/workspace).

## GitHub and PRs

| Command | Use |
| --- | --- |
| `griffin github` | GitHub agent for CI/Actions (`install`, `run`). |
| `griffin pr <number>` | Check out a PR branch, then launch the agent on it. |

## Project and lifecycle

| Command | Use |
| --- | --- |
| `griffin project` | Pin the Atlas project root for this folder (`merge`). |
| `griffin export` / `griffin import` | Export or import a session as JSON. |
| `griffin generate` | Emit the OpenAPI spec for the local server to stdout. |
| `griffin stats` | Local token-usage and cost stats. |
| `griffin debug` | Structured diagnostics for support (`debug paths` shows data/config dirs). |
| `griffin upgrade` | Update to the latest version. |
| `griffin uninstall` | Remove the binary and local config. |
| `griffin completion` | Shell completion for bash, zsh, or fish. |

```bash
griffin upgrade
griffin completion zsh > ~/.zsh/completions/_griffin
```
